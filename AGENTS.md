## Инструменты агента

В контейнере агента нет ни `make`, ни `docker`: окружение поднимается на хосте. Управлять им
агент может через [раннер целей на хосте](./tools/host-runner/README.md) — HTTP-канал,
разрешающий ровно цели `Makefile` из белого списка.

```bash
tools/host-runner/call.sh up
```

Доступные цели: `init`, `up`, `down`, `restart`. Раннер должен быть запущен на хосте; если он
недоступен, цель выполняет пользователь — самостоятельно поднимать окружение агент не может.

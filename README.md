# PDF Inverter

Клиентское веб-приложение, которое инвертирует цвета PDF (белое ↔ чёрное) и вырезает диапазон
страниц прямо в браузере, без бэкенда. Итог — новый PDF, готовый к скачиванию.

## Возможности

- Загрузка PDF локально: файл не покидает браузер пользователя.
- Простая попиксельная инверсия цвета (белый фон становится чёрным, чёрный текст — белым).
- Нарезка: необязательный диапазон «с какой по какую страницу»; пустой диапазон — весь документ.
- Два режима: «Инвертировать и скачать» (с растрированием) и «Только нарезать» — без инверсии
  и без потери качества (страницы копируются как есть, вектор и текст сохраняются).
- Скачивание нового PDF с индикацией прогресса.

---

## Как это работает

- **Инверсия**: `pdfjs-dist` (PDF.js) рендерит страницы на `<canvas>` в высоком разрешении
  (≈300 DPI), пиксели инвертируются на `ImageData` (`255 − значение` по каналам RGB), затем
  `pdf-lib` собирает новый PDF (страницы встраиваются как JPEG в исходном физическом размере).
- **Нарезка без инверсии**: `pdf-lib` копирует выбранные страницы исходника напрямую, без
  растрирования — качество не теряется.

Стек: React + Vite. Воркер PDF.js подключается как статический ассет и получает базовый путь
Vite, поэтому корректно работает из подкаталога GitHub Pages.

## Локальный запуск

```bash
npm ci
npm run dev
```

Приложение откроется по адресу, который выведет Vite (обычно `http://localhost:5173/pdf-inverter/`).

---

## Сборка

```bash
npm run build
npm run preview
```

`npm run build` формирует статику в каталог `dist/`. `npm run preview` поднимает локальный сервер
с учётом базового пути `/pdf-inverter/`.

## Деплой на GitHub Pages

Деплой автоматический: workflow [`.github/workflows/deploy.yml`](./.github/workflows/deploy.yml)
собирает приложение и публикует его при пуше в ветку `main`.

Разовая настройка репозитория:

1. Открыть `Settings` → `Pages`.
2. В `Build and deployment` → `Source` выбрать `GitHub Actions`.

После первого успешного прогона приложение доступно по адресу
`https://<user>.github.io/pdf-inverter/`.

> **Внимание:** если имя репозитория отличается от `pdf-inverter`, обновите `base`
> в [`vite.config.js`](./vite.config.js) на `/<имя-репозитория>/`.

## Ограничения

- **[DOC-020]** В режиме инверсии итоговый PDF растровый: страницы встраиваются как изображения
  (≈300 DPI), поэтому текст перестаёт выделяться и копироваться, а размер файла растёт
  относительно оригинала. Режим «Только нарезать» этого ограничения не имеет.
- Инверсия простая: фотографии и цветные иллюстрации превращаются в негатив.
- Обработка идёт в основном потоке браузера; очень большие PDF ограничены его памятью — для
  крупных файлов рекомендуется нарезка диапазоном.

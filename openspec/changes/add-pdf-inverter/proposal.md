## Why

Читать PDF-книги и документы со светлым фоном на экране неудобно и утомляет глаза, особенно в тёмное время. Нужен простой инструмент, который инвертирует цвета PDF (белое ↔ чёрное) и позволяет скачать готовый файл. Дополнительно часто требуется вырезать из большого PDF нужный диапазон страниц. Всё это должно работать целиком в браузере — без бэкенда, чтобы файлы пользователя никуда не загружались и приложение можно было бесплатно разместить на GitHub Pages.

## What Changes

- Новое клиентское веб-приложение на **React + Vite**, работающее полностью в браузере (без сервера).
- Загрузка PDF-файла пользователем локально (файл не покидает устройство).
- **Инверсия цвета**: рендер страниц через PDF.js, простая попиксельная инверсия (бело↔чёрное) на canvas.
- **Нарезка страниц**: опциональный ввод диапазона «с какой по какую страницу» при загрузке; в результат попадают только выбранные страницы.
- **Экспорт**: сборка и скачивание нового PDF из обработанных страниц (страницы становятся растровыми изображениями).
- Пайплайн деплоя: сборка Vite и автоматическая публикация на **GitHub Pages** через GitHub Actions.

## Capabilities

### New Capabilities

- `pdf-inversion`: рендер загруженного PDF в браузере, инверсия цветов страниц и экспорт результата в новый PDF для скачивания.
- `pdf-page-range`: выбор диапазона страниц при загрузке, влияющий на состав итогового PDF.
- `web-app-deployment`: статическая сборка фронтенда и автоматическая публикация на GitHub Pages без бэкенда.

## Impact

- **Новый код**: приложение React + Vite (UI загрузки, ввод диапазона, обработка и экспорт PDF).
- **Зависимости**: `react`, `react-dom`, `vite`; `pdfjs-dist` (рендер PDF); `pdf-lib` или `jspdf` (сборка итогового PDF).
- **Инфраструктура**: GitHub Actions workflow для сборки и деплоя на GitHub Pages; настройка `base` в конфиге Vite под путь Pages.
- **Ограничения**: экспортируемый PDF растровый (текст перестаёт выделяться, файл тяжелее оригинала); большие PDF ограничены памятью браузера.
- **Бэкенд**: отсутствует — вся обработка на стороне клиента.

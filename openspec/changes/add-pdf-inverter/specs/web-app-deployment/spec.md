## Purpose

Обеспечивает статическую сборку фронтенд-приложения и его автоматическую публикацию на GitHub Pages, чтобы инструмент был доступен по публичному URL без какого-либо бэкенда.

## ADDED Requirements

### Requirement: Статическая сборка без бэкенда

Система SHALL собираться в набор статических файлов (HTML/CSS/JS), не требующих серверной логики для работы.

#### Scenario: Продакшн-сборка

- **WHEN** запускается команда сборки приложения
- **THEN** формируется каталог статических артефактов, пригодных для размещения на статическом хостинге

#### Scenario: Работа из подкаталога Pages

- **WHEN** приложение открывается по URL вида `https://<user>.github.io/<repo>/`
- **THEN** все ресурсы (скрипты, воркер PDF.js, стили) загружаются корректно с учётом базового пути

### Requirement: Автоматический деплой на GitHub Pages

Система SHALL автоматически публиковать актуальную сборку на GitHub Pages при обновлении основной ветки репозитория.

#### Scenario: Публикация при пуше в основную ветку

- **WHEN** изменения попадают в основную ветку репозитория
- **THEN** пайплайн CI собирает приложение и публикует результат на GitHub Pages

#### Scenario: Провал сборки

- **WHEN** сборка приложения завершается ошибкой
- **THEN** пайплайн прекращает деплой и не публикует нерабочую версию

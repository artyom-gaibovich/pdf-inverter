## Purpose

Позволяет пользователю при загрузке PDF указать диапазон страниц «с какой по какую», чтобы в итоговый обработанный файл попали только выбранные страницы (нарезка документа).

## ADDED Requirements

### Requirement: Указание диапазона страниц

Система SHALL предоставлять при загрузке необязательный ввод начальной и конечной страницы диапазона. Если диапазон не задан, обрабатывается весь документ.

#### Scenario: Диапазон не задан

- **WHEN** пользователь загружает PDF и не указывает диапазон
- **THEN** система обрабатывает все страницы документа

#### Scenario: Задан корректный диапазон

- **WHEN** пользователь указывает начальную страницу N и конечную страницу M, где 1 ≤ N ≤ M ≤ число страниц
- **THEN** система обрабатывает и включает в результат только страницы с N по M включительно

### Requirement: Валидация диапазона

Система SHALL проверять корректность введённого диапазона относительно фактического числа страниц документа и не допускать обработку при некорректных значениях.

#### Scenario: Начало больше конца

- **WHEN** пользователь указывает начальную страницу больше конечной
- **THEN** система показывает сообщение об ошибке и не запускает обработку

#### Scenario: Выход за пределы документа

- **WHEN** пользователь указывает страницу меньше 1 или больше общего числа страниц
- **THEN** система показывает сообщение об ошибке и не запускает обработку

#### Scenario: Нечисловой или пустой ввод при частично заданном диапазоне

- **WHEN** пользователь вводит нечисловое значение в одно из полей диапазона
- **THEN** система показывает сообщение об ошибке и не запускает обработку

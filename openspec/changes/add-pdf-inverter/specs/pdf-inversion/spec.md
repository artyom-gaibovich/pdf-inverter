## Purpose

Позволяет пользователю загрузить PDF-файл в браузере, инвертировать цвета его страниц (белое ↔ чёрное) для комфортного чтения и скачать результат как новый PDF — вся обработка выполняется локально, без отправки файла на сервер.

## ADDED Requirements

### Requirement: Локальная загрузка PDF

Система SHALL принимать PDF-файл, выбранный пользователем, и обрабатывать его целиком в браузере без отправки данных на какой-либо сервер.

#### Scenario: Выбор корректного PDF

- **WHEN** пользователь выбирает файл с расширением `.pdf` корректной структуры
- **THEN** система загружает документ, определяет число страниц и переходит к настройке обработки

#### Scenario: Выбор файла неподдерживаемого формата

- **WHEN** пользователь выбирает файл, не являющийся корректным PDF
- **THEN** система показывает понятное сообщение об ошибке и не начинает обработку

#### Scenario: Приватность обработки

- **WHEN** пользователь загружает и обрабатывает PDF
- **THEN** содержимое файла не передаётся по сети, а обрабатывается только в браузере пользователя

### Requirement: Инверсия цвета страниц

Система SHALL выполнять простую попиксельную инверсию цвета (каждый цветовой канал заменяется на 255 минус его значение) для каждой обрабатываемой страницы.

#### Scenario: Инверсия светлой страницы

- **WHEN** страница имеет белый фон и чёрный текст
- **THEN** в результате фон становится чёрным, а текст — белым

#### Scenario: Сохранение геометрии страницы

- **WHEN** страница инвертируется
- **THEN** размер, пропорции и порядок следования страниц сохраняются

### Requirement: Экспорт результата в PDF

Система SHALL собирать обработанные страницы в новый PDF-файл и предоставлять его пользователю для скачивания.

#### Scenario: Скачивание готового файла

- **WHEN** обработка страниц завершена и пользователь запускает экспорт
- **THEN** система формирует новый PDF из инвертированных страниц и инициирует его скачивание в браузере

#### Scenario: Индикация процесса

- **WHEN** обработка многостраничного PDF выполняется
- **THEN** система отображает индикатор прогресса или состояние обработки до готовности файла
